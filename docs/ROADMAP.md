# Roadmap

## Near term

- Grafana scraping of `/metrics`
- More Kafka topics (`customer-events`, `sales-events`)
- Content recommendation heuristics from creative CTR

## Medium term

- Real OAuth connectors (Meta, Google Ads, TikTok, HubSpot, Shopify, GA4)
- LLM swap behind `IntelligenceEngine` (OpenAI / LangChain) with offline fallback
- Celery beat for multi-tenant morning reports

## Longer term

- Scala Spark cluster for large-scale feature engineering
- Kubernetes Helm chart
- SSO, billing, SLA dashboards
